# USEN PAY 代理店事業（株式会社YST）

このフォルダは、株式会社YSTが 2026年10月に稼働開始した「USEN PAY」販売代理店事業のうち、
**公開しても問題ない部分だけ** を置く場所です。

> このリポジトリは公開（GitHub Pages で誰でも閲覧可）です。
> 手数料率・代理店報酬・契約条件・ログイン情報・担当者の連絡先などの機密情報は、
> ここには絶対に書かず、Google Drive の「USEN PAY 代理店（株式会社YST）」フォルダで管理します。

## このフォルダにあるもの

| ファイル | 内容 | 公開状態 |

| `index.html` | 店舗向けの USEN PAY 導入相談ページ（LP）。電話・メールでの問い合わせ導線つき | **公開前ドラフト**。main にマージすると GitHub Pages で `/usen-pay/` として公開される |
| `README.md` | この説明 | — |

## 公開前にやること（LP）

1. USEN から配布されている営業ガイドラインで、表現・商標表記（「USEN PAY」）・キャンペーン表記を確認する。
2. 「※条件あり」「※内容は変更される場合があります」の注記が残っていることを確認する。
3. 電話番号・メールアドレスが現在のものか確認する（`index.html` 内の `tel:` と `mailto:` を検索）。
4. 問題なければ Pull Request を main にマージする。

## 内部資料の置き場所（Google Drive）

Google Drive の「USEN PAY 代理店（株式会社YST）」フォルダに、次の資料があります。

- 運用マニュアル（申込みの流れ、報酬の仕組み、毎月のやること、連絡先）
- USEN からのメール時系列まとめ
- 案件管理・報酬シミュレーター（スプレッドシート）
- USEN から受領した資料（条件通知書、商材一覧、申請書テンプレート など）

## 編集のしかた（初心者向け）

- `index.html` は 1 ファイルで完結しています（外部の JavaScript や画像は使っていません）。
- 文言を直したいときは、ブラウザで表示されている文章をそのまま検索して該当箇所を書き換えます。
- 色を変えたいときは、`<style>` の先頭にある `:root { ... }` の色コードを変更します。
- 変更後はスマートフォン幅（390px 程度）とパソコン幅の両方で表示崩れがないか確認します。
